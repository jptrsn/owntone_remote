# 08 — Albums tab (LibraryViewActivity)

Alphabetical ListView by album name; row = name + right accessory
(presumed play, not tapped). Long-press = tap (drill-in).
Tap → SongsViewActivity (album songs, 09). Grid variant exists (View as).

## JSON mapping
- `GET /api/library/albums?query=&cc=album` (paginated).
