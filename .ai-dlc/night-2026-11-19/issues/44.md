# Add a navigation drawer (ReTune-style) — hamburger on every screen

(Canonical: https://github.com/jptrsn/owntone_remote/issues/44. Frozen copy for the 2026-11-19 overnight run.)


## Change
The app has no navigation widget: Now Playing is the root route and
Library/Queue/Outputs/Settings are pushed on top
(`root_screen.dart:11-20,34-42`); the only nav affordances are three
entry buttons **on Now Playing** (`now_playing_screen.dart:321-366`).
Getting to Queue from a deep browse screen means backing out to root.
User decision 2026-11-19 (diff-list N-02 **option B**): adopt ReTune's
drawer pattern.

## Expected
Material 3 `Drawer` behind a hamburger on **every main screen** (Now
Playing + every `BrowseScreenScaffold` screen incl. Queue/Outputs/Settings;
ReTune's missing-drawer-on-UpNext quirk is NOT copied —
`docs/retune-capture/23-playing-audit/notes.md`):
- Header: **Connected To — <server name>** (`/api/config` display name).
- Section **Playing**: Now Playing · Queue.
- Section **Library**: Library home (+ direct deep links to Playlists/
  Artists/Albums/Songs — Songs per #38/R-15 — Genres).
- Section **Settings**: Settings (server + rocker step) · Outputs.
- Selecting from a pushed screen = `popUntil(isFirst)` **then** push —
  never stack a duplicate route (see the `showNowPlaying` doc-comment
  warning, `root_screen.dart:9-20`; a regression asserting stack depth is
  part of the tests).
- Selected destination: `Semantics(selected:)` (ReTune exposes no
  selection state at all — do better; unit-009 precedent).
- Back closes the drawer first (standard Scaffold behaviour — assert it).
- Offline: drawer opens; server-touching destinations inert (existing
  banner/enabled contract).

## Where
New `lib/src/ui/app_drawer.dart`; wire `drawer:` into
`now_playing_screen.dart` (Scaffold), `browse_screen_scaffold.dart`
(+`drawer` param, mirrors existing `actions:` at `:26,80`), and the
standalone Scaffolds (outputs/settings). Route helpers next to
`showNowPlaying` in `root_screen.dart`.

## Requirements
R-21. Pairs with the mini-transport-bar issue (bottom bar when a track is
playing — same audit).

## Repro / verification
Widget tests (fake providers): hamburger found on Library/Queue/Outputs/
Settings/NP routes; tapping Queue from two-deep browse yields route stack
of depth 2 (root NP + queue), **not** duplicates; selected semantics
present; offline → items inert. Device: manual drawer pass (no audio).
Gates green.
