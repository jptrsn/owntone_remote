# Issue #19 (frozen spec — source of truth for the overnight run; canonical: https://github.com/jptrsn/owntone_remote/issues/19)

Volume controls should be disabled for unselected outputs (match OwnTone UI)

## Defect
Volume sliders/controls for **unselected** outputs are currently interactive. OwnTone's own web UI disables volume control for outputs that are not selected.

## Expected
Volume control rendered disabled (but visible) for every output where `selected == false`, matching the OwnTone UI/UX. Selection state arrives over the websocket, so enabling/disabling must follow the live `outputs` update.

## Where
`lib/src/ui/outputs_screen.dart`, `lib/src/outputs/outputs_controller.dart`, `lib/src/outputs/output.dart`.

## Repro / verification
Disposable AVD + flutter-agent-lens (widget tree): an unselected output's slider must be disabled while a selected one stays live; toggle selection server-side and confirm the UI follows. Server is shared — enable/disable outputs only while paused (safe per AGENTS), never start audio.
