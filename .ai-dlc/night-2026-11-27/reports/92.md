## SUMMARY

Built the transient volume toaster per capture-22 parity: `VolumeToasterLayer`
mounted above the Navigator via `MaterialApp(builder:)` (the only slot that
renders over opaque pushed routes), driven by two new `PlayerController`
fields (`volumeStepSeq`/`volumeStepLevel`) bumped in `stepVolume` under
`_action`'s request gate (`api != null && isConnected && _player != null`)
using the same clamp expression as the optimistic copy — so the bar label is
the slice value the NowPlaying slider renders, by construction. The bar is an
`IgnorePointer` + `ExcludeSemantics` Material pill (`Align.center` → device
center inside the y900–1500 band) with a 1500 ms single auto-hide `Timer`
(repeat press resets in place, never a stack). NP-root suppression is a
push-depth gate: `VolumeToasterRouteObserver` (a `NavigatorObserver` on
`MaterialApp`) hides the layer whenever depth ≤ 1, so the 0–100 slider stays
the only NP indicator (#92 AC-2). Offline/no-first-slice presses stay visually
inert (AC-4). `OwntoneRemoteApp` became a `StatefulWidget` only to own one
stable observer instance (public `toaster` getter for tests). 12 tests added
(11 new + T12 in `rocker_foreground_test.dart`); all four gates green; device
pass ran on the per-unit AVD `OwnToneNight27_API_36` (created and deleted by
this unit) with D-1/D-2/D-3 PASS, H-1/H-2 BLOCKED-PENDING-HOST-VERIFICATION
per plan, server restored to volume 46 (verified) and outputs untouched.
